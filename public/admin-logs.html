Logs & Inference

Administrator-only operational diagnostics. Manuscript text, prompts, API credentials and session tokens are excluded.

Inference data is aggregated across pool consumers, not exclusively Book Studio. HTTP success is not a measure of writing quality. The activity feed currently contains structured lifecycle events, not every user action or a complete audit trail.
