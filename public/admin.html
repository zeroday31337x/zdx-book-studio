Usage & inference cost

Every model call in the pipeline (write, continuation, length repair, review, FrictionWrite, design) is metered with real provider token counts, latency, and rate-card cost. Costs use the configured rate card; self-hosted inference-pool models default to $0/token, so for pool models the tokens and latency are the resource measures. Tracking starts when this build is deployed; earlier production is not backfilled.

Platform settings

Product options live in the database and take effect without a restart or file edits. Where a value comes from is shown beside each field: db (saved here), env (server fallback), default (built in). Secrets and provider API keys never live here; they stay in the server environment.

Users & subscription tiers

Plans: Basic $49.99/month (5 books, 30 chapters/book, 3,000 words/chapter); Premium $99.99/month (25 books, 200 chapters/book, 10,000 words/chapter). Pricing is informational; no billing is activated. Existing books are preserved if an account is disabled or removed.
